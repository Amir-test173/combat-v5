# World Dominion v1.3 — Provinces, Recruitment & Defenses

هذه النسخة مبنية فوق v1.2 Combat ولا تحذف أي نظام سابق.

## ما أضيف
- بنية محافظة/ولاية داخل كل دولة مع مالك مستقل، حامية، مستوى تحصين، مقاومة ومعسكرات تدريب محلية.
- احتلال تدريجي محافظة بمحافظة: سقوط محافظة لا يسقط الدولة، وتنتقل الدولة كاملة فقط بعد سقوط آخر محافظة خاضعة للمدافع.
- دفاع المحافظة يدخل في حساب الجولة: الحامية + التحصين، إضافة إلى دفاع الحدود الوطني.
- ذهب كموارد مستقلة، مع إنتاج دوري.
- شراء/تدريب المشاة بالذهب والموارد.
- سعة تدريب تعتمد على السكان وتزداد ببناء معسكرات تدريب، وتُعاد عند بداية الدور الجديد.
- بناء دفاعات حدودية وطنية، وتحسين تحصين كل محافظة، ونقل جنود إلى حاميتها.
- نمطان للحرب: Manual للاستمرار في التخطيط/التعزيز/الانسحاب، وAuto لحسم الجولات تلقائياً باستخدام نفس قواعد المعركة.
- Protocol 4 للسيرفر والتطبيق.
- مسار بيانات عالمي: أثناء GitHub Actions يتم إنشاء Asset أوفلاين من بيانات دول مستقلة + حدود + تقسيمات إدارية من مصادر مفتوحة. بعد بناء APK لا يحتاج التطبيق للإنترنت لقراءة هذه البيانات.

## بيانات العالم
الملف `tool/fetch_world_data.py` يجلب أثناء البناء:
- mledoze/countries: الدول، ISO2/ISO3، السكان، الإحداثيات، الحدود البرية، landlocked، والأسماء/الترجمات.
- country-regions/country-region-data: التقسيمات الإدارية الأولى (ولايات/محافظات/مناطق).

يوجد Asset احتياطي صغير داخل ZIP لكي لا يفشل المشروع إذا لم تتوفر الشبكة أثناء التطوير المحلي. GitHub Actions يستبدله ببيانات العالم الكاملة قبل `flutter analyze/test/build`.

## ما لم أصفه بأنه مكتمل بعد
- الترجمة العربية/الإنجليزية لكل نص في كل شاشة ليست مكتملة بعد؛ أضيف مفتاح اللغة وبنية الترجمة وبعض الشاشات الأساسية فقط.
- حدود المحافظات الرسومية الدقيقة على الخريطة ليست مضافة بعد؛ المحافظات موجودة ككيانات لعب وسيطرة لكن الخريطة السياسية ما تزال ترسم حدود الدول.
- نظام مدة المباراة (سريع/عادي/ملحمي) لم يُربط بعد بالغرف؛ الحفظ يجعل اللعب الفردي قابلًا للاستمرار، لكن Multiplayer يحتاج إعداد pacing أعمق للجولات الطويلة.
- لم يتم تشغيل `flutter analyze/test/build` محلياً هنا لغياب Flutter SDK؛ GitHub Actions هو مسار الفحص والبناء الحقيقي.
